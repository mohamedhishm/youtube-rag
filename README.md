# YouTube Video RAG Assistant

A Python application that allows users to ask questions
about YouTube videos and receive answers grounded in
the video transcript.

## Tech Stack

- Python
- FastAPI
- Retrieval-Augmented Generation (RAG)
- Embeddings and vector search

## Project Structure

- `app/`: Backend application and API
- `transcript/`: Transcript extraction and processing
- `retrieval/`: Relevant context retrieval
- `frontend/`: User interface
- `tests/`: Automated tests

## Setup

1. Create a virtual environment.
2. Install dependencies.
3. Configure environment variables.
4. Run the FastAPI server.
